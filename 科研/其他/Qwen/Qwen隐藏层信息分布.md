# Qwen3-VL 隐藏层信息分布

本文补充 [[Qwen3-VL-4B架构讲解]] 中对视觉编码器、DeepStack 与语言模型隐藏状态的说明。

**隐藏层中的信息不是按“第 6 层只存边缘、第 12 层只存文字”这样整齐划分的。** 信息以分布式、叠加的方式存在于大量神经元中。官方只明确说明 DeepStack 利用了从低层到高层的多级视觉表示，并没有公布逐层语义探针实验。

下面的“信息类型”是基于 Transformer 表征规律和模型数据流的机制性解释。

## 一、视觉编码器的隐藏层

视觉编码器只接收图片，不接收用户问题。因此这些隐藏状态描述的是图片本身，尚未针对问题进行推理。

| 位置 | 张量形状 | 通常更容易保留的信息 |
| --- | --- | --- |
| Patch Embedding | $N_{\text{patch}} \times 1024$ | 16×16 局部区域的颜色、亮度、纹理、笔画和位置 |
| 第 1–6 层 | $N_{\text{patch}} \times 1024$ | 局部视觉模式、边缘、纹理、细小形状、字符笔画，同时已包含部分全局上下文 |
| 第 7–12 层 | 同上 | 局部模式组合、物体部件、字符结构、局部版面、重复图案 |
| 第 13–18 层 | 同上 | 物体和区域表示、属性、区域间关系、版面结构 |
| 第 19–24 层 | 同上 | 更抽象的物体类别、场景语义、全局构图和高层视觉概念 |

这些只是“倾向”，不是严格边界。由于视觉层使用全局自注意力，从第一层开始，每个视觉 Token 就可能接收其他位置的信息。

### 四组关键视觉隐藏状态

```text
X⁽⁶⁾   相对偏向细节和较浅层模式
  └─→ DeepStack Merger 1

X⁽¹²⁾  局部结构与中层模式
  └─→ DeepStack Merger 2

X⁽¹⁸⁾  区域、物体与较高层语义
  └─→ DeepStack Merger 3

X⁽²⁴⁾  最终、最抽象的视觉表示
  └─→ 主 Visual Merger
```

[INFERRED|MED] 可以把它们简单理解为：

$$
X^{(6)}:\text{细节偏多}
\rightarrow
X^{(12)}:\text{结构组合}
\rightarrow
X^{(18)}:\text{对象与区域}
\rightarrow
X^{(24)}:\text{全局语义}
$$

但不能写成：

```text
第6层 = OCR
第12层 = 物体
第18层 = 空间关系
第24层 = 场景
```

因为 OCR、定位和物体识别通常都依赖多层信息共同完成。

## 二、语言模型的隐藏层

视觉最终特征替换 `<|image_pad|>` 后，语言模型初始隐藏状态为：

$$
H^{(0)} \in \mathbb{R}^{B \times L \times 2560}
$$

它同时包含：

- 文本 Token Embedding；
- 最终视觉 Token $V_{\text{main}}$；
- 文本和视觉位置关系；
- 角色、图片边界等特殊 Token。

### 前三层：DeepStack 融合

数据流实际上是：

```text
H⁽⁰⁾：文本 + 第24层主视觉特征
  ↓ Decoder Layer 1
H⁽¹⁾ + 第6层 DeepStack 特征
  ↓ Decoder Layer 2
H⁽²⁾ + 第12层 DeepStack 特征
  ↓ Decoder Layer 3
H⁽³⁾ + 第18层 DeepStack 特征
```

| 语言层位置 | 隐藏状态中增加的信息 |
| --- | --- |
| 输入 $H^{(0)}$ | 文本内容和最终高层视觉语义 |
| 第 1 层之后 | 初步文本—图像交互，再补充相对浅层视觉信息 |
| 第 2 层之后 | 更进一步的跨模态融合，再补充中层视觉结构 |
| 第 3 层之后 | 融合结果再加入较高层区域和物体表示 |

需要注意：DeepStack 特征是在对应 Decoder Layer **计算完成后残差加入**，因此第 6 层视觉特征主要从语言模型第 2 层开始影响后续计算。

### 第 4–36 层：理解、推理与输出

官方没有给出“第几层固定负责什么”的划分。通常可以作如下理解：

| 语言层范围 | 通常偏向的信息处理 |
| --- | --- |
| 第 4–12 层 | 文本含义、视觉区域和问题之间的初步对应，属性与局部关系整合 |
| 第 13–24 层 | 跨模态组合、空间关系、计数、比较、OCR 上下文和多步推理 |
| 第 25–36 层 | 收敛到任务答案，组织语言、坐标或结构化格式，准备下一个 Token 的预测 |

[INFERRED|MED] 这种“前期融合—中期推理—后期输出”的分法是理解模型的框架，不是官方验证过的逐层功能表。

## 三、不同任务会使用哪些信息

### OCR

```text
字符笔画和局部纹理
    ↓
字符结构和局部版面
    ↓
词语、句子和上下文
    ↓
语言模型生成识别结果
```

OCR 并非只由第 6 层完成，而是浅层视觉细节、中层字符结构和语言上下文共同作用。

### 目标定位

```text
局部边界和区域特征
 + 视觉网格位置
 + 物体语义
 + Interleaved-MRoPE
 + 定位训练数据
 → 坐标文本
```

### 图像问答

```text
最终视觉语义
 + DeepStack 多层细节
 + 问题文本
 → 跨模态对应
 → 推理
 → 答案生成
```

## 四、结论

[KNOWN|HIGH] Qwen3‑VL 的视觉隐藏状态从第 6、12、18 层经过专用 Merger，分别加入语言模型前三层之后的视觉 Token 隐藏状态；第 24 层视觉输出则构成语言模型输入中的主视觉 Token。

核验依据：

- [Qwen3-VL Technical Report](https://arxiv.org/abs/2511.21631)
- [Qwen3-VL 官方 Transformers 实现](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen3_vl/modeling_qwen3_vl.py)

可以用一句话概括：

> 视觉浅层相对保留更多局部细节，视觉深层形成更抽象的图片表示；语言模型前层融合文本与视觉，中间层进行关系组合和推理，后层将这些信息组织成最终输出，但这些功能是重叠分布的，并不存在严格的一层一功能。
