# 损失函数（Loss Function）

> [!abstract] 核心结论
> 损失函数是实际目标的可优化代理，它定义模型在训练中把什么视为错误，以及不同错误应承担多大代价。合理选择需要同时考虑任务定义、输出含义、标签形式、数据分布和最终评价指标；不存在脱离这些条件的“最佳损失”。

## 核心概念

损失函数把模型预测与监督信号之间的差异映射为一个可优化的标量。它既提供梯度信号，也隐含了对误差形式、噪声分布和样本重要性的判断。训练时通常最小化小批量平均损失：

$$
\mathcal L(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f_\theta(x_i),y_i).
$$

其中 $f_\theta$ 为模型、$y_i$ 为监督信号、$\ell$ 为单个样本或局部单元的损失。监督信号可以是类别、数值、序列、掩码或概率分布。损失不必等于最终业务指标；模型输出、标签编码和损失函数必须配套。相关输出层见 [[激活函数]]。

**例子**：分类模型常以交叉熵训练，却以准确率、F1 或 AUROC 评估。交叉熵下降说明概率输出更贴近标签，但不能单独证明阈值决策或类别排序已经满足最终需求。

默认损失对 batch 取平均；不同框架的 `sum` 或 `mean` 归约方式会改变梯度尺度。

## 常见方法

### 均方误差（MSE）

**定义**：对回归预测 $\hat y$ 与目标 $y$ 的误差平方求平均：

$$
\operatorname{MSE}(\hat y,y)=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2.
$$

平方函数在零点附近平滑、处处给出连续梯度，而且残差越大，梯度绝对值越大，因此优化器会优先纠正大误差。若目标关心条件均值，或大偏差确实应承担更高代价，MSE 与该目标较匹配。

**作用与局限**：平方会更强地惩罚大误差；在“标签等于真实值加独立同方差高斯噪声”的假设下，最小化 MSE 对应最大似然估计。它对离群点敏感：单个很大的误差可能主导训练。

**例子**：$y=[1,3]$、$\hat y=[2,1]$ 时，误差为 $[1,-2]$，MSE 为 $(1^2+(-2)^2)/2=2.5$。两个样本的平方误差分别为 $1$ 和 $4$，因此第二个样本贡献了总误差的 $80\%$，体现了 MSE 对较大残差的强调。

### 平均绝对误差（MAE / L1）

**定义**：对误差绝对值求平均：

$$
\operatorname{MAE}(\hat y,y)=\frac{1}{n}\sum_{i=1}^{n}|\hat y_i-y_i|.
$$

绝对值让每增加一个单位的误差都付出相同的边际代价，不会像平方那样让少数极端残差获得成倍权重。因此，当评价本身使用绝对误差、目标更接近条件中位数，或数据含少量重尾噪声时，MAE 往往更贴合问题。

**作用与局限**：其惩罚随误差线性增长，通常比 MSE 更不受离群点影响；对应条件中位数而非条件均值的估计。绝对值在零点不可导，但可取次梯度，现代自动微分框架可直接优化。误差较大时，MAE 的梯度大小不随误差增大而增大，收敛可能较慢。

**例子**：沿用上例，MAE 为 $(|1|+|-2|)/2=1.5$。若第二个预测改为 $-7$，第二项误差从 $2$ 增至 $10$：MSE 的该项从 $4$ 增至 $100$，MAE 则从 $2$ 增至 $10$。

### Huber 损失（Smooth L1）

**定义**：令残差 $r=\hat y-y$，给定阈值 $\delta>0$：

$$
\ell_\delta(r)=
\begin{cases}
\frac{1}{2}r^2,& |r|\le\delta,\\
\delta\left(|r|-\frac{1}{2}\delta\right),& |r|>\delta.
\end{cases}
$$

Huber 在预测已接近目标时保留二次损失的平滑梯度，在残差过大时把梯度限制在线性增长范围内。这样既能细致优化小误差，又避免可疑离群点完全支配一次更新，是 MSE 与 MAE 之间可调的折中。

**作用与局限**：小误差区域像 MSE 一样平滑，大误差区域像 MAE 一样线性，因此常用于存在少量异常标注或定位偏差的回归问题。$\delta$ 决定二次区间的宽度，且其精确参数化在不同框架中可能不同，应查阅所用 API 的定义。

**例子**：取 $\delta=1$。$r=0.5$ 时损失为 $0.5\times0.5^2=0.125$；$r=3$ 时损失为 $1\times(3-0.5)=2.5$，明显小于同一残差的平方损失 $9$。

### 二元交叉熵（Binary Cross-Entropy，BCE）

**定义**：对二分类标签 $y\in\{0,1\}$ 和正类概率 $p\in(0,1)$：

$$
\operatorname{BCE}(p,y)=-\bigl[y\log p+(1-y)\log(1-p)\bigr].
$$

若模型给出 logit $z$，则 $p=\sigma(z)$。实践中优先使用直接接收 $z$ 的 `BCEWithLogitsLoss`，而非手动 `sigmoid` 后再计算 BCE，以避免 $p$ 极接近 $0$ 或 $1$ 时的数值问题。

BCE 是伯努利标签的负对数似然。正确类别概率越低，损失增长越快，因此模型不能只把样本放到阈值的正确一侧，还会被推动去提高正确标签的概率；每个输出独立建模时，它也自然适用于多标签任务。

**作用与局限**：它鼓励真实类获得高概率，并对自信但错误的预测施加很大惩罚。二分类的输出通常为一个 logit；多标签分类中，每一类也使用一个独立 logit 和 BCE，类别概率不要求和为 $1$。

**例子**：若 $y=1$、$p=0.9$，损失为 $-\log0.9\approx0.105$；若仍预测正类但 $p=0.1$，损失为 $-\log0.1\approx2.303$。

### 多类交叉熵（Cross-Entropy，CE）

**定义**：单标签 $K$ 分类中，模型输出 logits $z\in\mathbb R^K$，softmax 概率为

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}.
$$

若真实类别索引为 $c$，交叉熵为

$$
\operatorname{CE}(z,c)=-\log p_c
=-z_c+\log\sum_{j=1}^{K}e^{z_j}.
$$

softmax 让互斥类别在同一概率总量中竞争，交叉熵再提高真实类相对其他类的 logit。它提供连续梯度，即使当前分类已经正确，也能继续优化类别间的置信差距，因此通常比直接优化不可导的准确率更适合训练。

**作用与局限**：用于互斥的单标签多分类，如一张图只属于一个类别。常用 `CrossEntropyLoss` 接收未归一化 logits 和类别索引；不要先手动做 softmax。稳定实现会使用 log-sum-exp 技巧。若标签为 one-hot 向量，公式等价于 $-\sum_k y_k\log p_k$，但许多框架默认接收类别索引。

**例子**：三个类别的 logits 为 $[2,1,0]$，真实类别为第一个。softmax 概率约为 $[0.665,0.245,0.090]$，损失为 $-\log0.665\approx0.408$。将所有 logits 同时加上常数不改变 softmax 或该损失。

### 标签平滑（Label Smoothing）

**定义**：在 $K$ 类分类中，将 one-hot 目标 $y$ 替换为平滑目标

$$
q_k=(1-\varepsilon)y_k+\frac{\varepsilon}{K}.
$$

其中 $0\le\varepsilon<1$，随后计算 $-\sum_k q_k\log p_k$。

one-hot 目标要求模型把全部概率压到单一类别，即使标签可能含噪声或类别之间存在相似性。平滑后，极端 logit 差距不再持续获得同样收益，相当于削弱“无限提高训练置信度”的动力，从而可能减少对错误标签和偶然细节的拟合。

**作用与局限**：标签平滑减少模型对训练标签的极端自信，常作为提升泛化或概率校准的正则化手段。它不是总会提高准确率，且在标签本身高度可靠、需要极尖锐分布或要蒸馏软标签时，平滑强度需谨慎选择。

**例子**：$K=3$、$\varepsilon=0.1$，真实类别为第一个时，目标由 $[1,0,0]$ 变为 $[0.933,0.033,0.033]$；模型即使给真实类接近 $1$ 的概率，也仍会因其他类概率过低受到轻微惩罚。

### 焦点损失（Focal Loss）

**定义**：令 $p_t$ 是真实类别的预测概率，二分类焦点损失可写为

$$
\operatorname{FL}(p_t)=-\alpha_t(1-p_t)^\gamma\log p_t,
$$

其中 $\gamma\ge0$ 控制对易样本的下调程度，$\alpha_t$ 可平衡类别权重。$\gamma=0$ 时退化为加权交叉熵。

在大量易负样本已经被正确识别后，普通交叉熵的这些小损失相加仍可能淹没少量困难样本。调制因子会随 $p_t$ 增大而快速减小，使优化预算更多落在错分或低置信样本上；这正是密集检测中前景稀少时采用它的主要原因。

**作用与局限**：当样本已被正确且高置信地分类时，$(1-p_t)^\gamma$ 很小，损失被压低；困难样本相对获得更多权重。它适合极端前景/背景不均衡等场景，但会改变训练目标和概率校准，不能把它当作所有不均衡分类的默认替代品。

**例子**：取 $\gamma=2$ 且暂不考虑 $\alpha_t$。易正样本 $p_t=0.9$ 的交叉熵约为 $0.105$，乘以调制因子 $0.01$ 后约为 $0.001$；困难正样本 $p_t=0.2$ 的交叉熵约为 $1.609$，乘以 $0.64$ 后约为 $1.030$。因此训练信号会明显集中到困难样本。

### Dice 损失与 IoU 损失

**定义**：对二值分割的预测概率向量 $p$ 和标签向量 $y$，软 Dice 系数常写为

$$
\begin{aligned}
\operatorname{Dice}(p,y)
&=\frac{2\sum_i p_i y_i+\epsilon}{\sum_i p_i+\sum_i y_i+\epsilon},\\
\mathcal L_{\mathrm{Dice}}
&=1-\operatorname{Dice}(p,y).
\end{aligned}
$$

软 IoU（Jaccard）可写为

$$
\begin{aligned}
\operatorname{IoU}(p,y)
&=\frac{\sum_i p_i y_i+\epsilon}{\sum_i p_i+\sum_i y_i-\sum_i p_i y_i+\epsilon},\\
\mathcal L_{\mathrm{IoU}}
&=1-\operatorname{IoU}(p,y).
\end{aligned}
$$

像素级 BCE/CE 分别计算每个位置，背景很多时，总损失可能主要反映“把背景判对”。Dice 和 IoU 先聚合交集与预测、真实区域的大小，再衡量整体重叠，因此一个小前景不会仅因像素少就完全失去影响。

**作用与局限**：二者直接关注区域重叠，常用于前景很小的分割任务。$\epsilon$ 用于避免分母为零，其位置和多类聚合方式会因实现而异。Dice/IoU 对单图或单类统计可能不稳定，实践中常与 BCE 或 CE 联合使用，而不是仅凭名称任选其一。

**例子**：若二值预测与标签均为 $[1,1,0,0]$，Dice 和 IoU 都为 $1$。若预测为 $[1,0,0,0]$、标签仍为 $[1,1,0,0]$，则 Dice 为 $2/3$，IoU 为 $1/2$；IoU 对未覆盖区域的惩罚更强。

### KL 散度与知识蒸馏

**定义**：对目标分布 $q$ 与预测分布 $p$：

$$
D_{\mathrm{KL}}(q\Vert p)=\sum_k q_k\log\frac{q_k}{p_k}.
$$

由于 $D_{\mathrm{KL}}(q\Vert p)=H(q,p)-H(q)$，在固定 $q$ 时，最小化 KL 散度与最小化交叉熵 $H(q,p)$ 等价。

硬标签只说明哪个类别正确，软分布还包含“其他类别有多像”的相对信息。以教师分布为 $q$ 时，KL 会推动学生复现这整组关系，因此学生可获得比单个类别索引更丰富的监督；前提是教师分布本身具有可信信息。

**作用与局限**：KL 散度不对称，$D_{\mathrm{KL}}(q\Vert p)$ 与 $D_{\mathrm{KL}}(p\Vert q)$ 的优化行为不同。知识蒸馏通常把教师模型的软概率作为 $q$，让学生同时学习硬标签和类别间的相对关系；教师与学生的温度、方向及缩放必须和具体实现一致。

**例子**：$q=[0.8,0.2]$、$p=[0.8,0.2]$ 时 KL 为 $0$。若预测反转为 $p=[0.2,0.8]$，则

$$
D_{\mathrm{KL}}(q\Vert p)=0.8\log4+0.2\log0.25\approx0.832.
$$

该值表示预测分布与目标分布明显不一致；KL 不是通常意义的距离，因为交换 $p,q$ 后一般不会得到相同结果。

## 作用与局限

损失函数把“希望模型学到什么”转化为可微的训练信号，并决定模型会优先减少哪类误差；它不能单独保证最终指标、阈值决策或概率校准都更好。损失与业务指标不一致、标签噪声严重、类别分布变化，或优化未收敛时，较低的训练损失都不足以证明模型更适用。因此应在独立验证集上按目标指标比较候选损失，而不是只比较训练损失的绝对值。

| 维度 | 主要作用 | 核心局限或风险 |
| --- | --- | --- |
| 优化信号 | 将训练目标转换为可计算、通常可微的标量 | 可优化不等于与最终业务目标完全一致 |
| 误差偏好 | 决定大误差、小误差、少数类或困难样本的相对权重 | 权重设计不当会忽略关键错误或放大噪声 |
| 统计假设 | 用特定目标刻画预测与数据生成过程的关系 | 噪声分布、标签质量或独立性假设不匹配时会产生偏差 |
| 样本与结构聚合 | 将样本、像素、时间步或类别的局部误差汇总为整体目标 | 聚合方式可能掩盖小群体、小目标或局部失败 |
| 训练尺度 | 通过 `mean`、`sum`、权重和掩码控制梯度量级 | batch size、有效元素数和分布式归约会改变梯度尺度 |

**例子**：两个分类模型的验证交叉熵分别为 $0.30$ 和 $0.28$，但后者在固定阈值下的少数类 F1 更低。这说明损失更小只代表更贴近训练目标，最终仍需按业务指标调阈值并比较模型。

## 相关知识

### 任务、输出与损失函数的匹配

| 任务 | 模型输出 | 标签形式 | 常用损失 |
| --- | --- | --- | --- |
| 标量回归 | 实数 | 实数 | MSE、MAE、Huber |
| 二分类 | 一个 logit | $0/1$ | `BCEWithLogitsLoss` |
| 单标签 $K$ 分类 | $K$ 个 logits | 类别索引 | `CrossEntropyLoss` |
| 多标签 $K$ 分类 | $K$ 个独立 logits | $K$ 维 $0/1$ 向量 | `BCEWithLogitsLoss` |
| 语义分割 | 每像素 logits | 每像素类别/掩码 | CE 或 BCE，常配合 Dice/IoU |
| 软目标、蒸馏 | 概率或 log-probability | 概率分布 | 交叉熵、KL 散度 |

**例子**：同样是识别“猫、狗、汽车”，若每张图只允许一个类别，三个 logits 应共同经过多类交叉熵，因为提高“猫”的概率会压低其他类别；若一张图可以同时含“猫”和“汽车”，则三个标签彼此独立，应使用三个 logits 的 BCE。两种模型都输出 3 个数，但标签语义和类别间约束不同，不能仅按输出形状选择损失。

## 如何选择与诊断

| 场景或现象 | 优先选择或动作 | 重点检查 |
| --- | --- | --- |
| 开始定义训练目标 | 先确定输出含义和标签形式，再从任务匹配表选择候选损失 | 单标签与多标签、数值与概率、逐样本与逐像素是否区分正确 |
| 训练分类模型 | 将 logits 直接交给框架提供的稳定损失实现 | 是否在 `CrossEntropyLoss` 前重复 softmax，或在 `BCEWithLogitsLoss` 前重复 sigmoid |
| 类别或前景极不均衡 | 先统计各类样本与目标尺寸，再比较类别权重、重采样、Focal Loss 或联合损失 | 少数类召回率、PR-AUC、F1 等指标是否随总体损失同步改善 |
| 损失下降但业务指标不升 | 检查阈值、数据划分、标签噪声、样本权重与指标对齐 | 是否存在数据泄漏、分布偏移或由固定阈值造成的评价偏差 |
| 损失出现 NaN / Inf | 检查标签范围、学习率、混合精度、归约方式和重复激活 | 逐步缩小到首个异常 batch，并核对输入与 logits 的数值范围 |

## 综合例子

### 房价预测：回归

模型对两套房的预测为 $\hat y=[120,180]$（万元），真实价格为 $y=[100,200]$。残差为 $[20,-20]$，所以 MSE 为 $400$，MAE 为 $20$。若第三套房标签因录入错误变为 $1\,000$、预测仍为 $180$，其平方误差为 $672\,400$，会主导 MSE；这种情况下可在验证集上比较 Huber 与 MSE。

```python
import torch
import torch.nn.functional as F

prediction = torch.tensor([120.0, 180.0])
target = torch.tensor([100.0, 200.0])
mse = F.mse_loss(prediction, target)       # 400.0
mae = F.l1_loss(prediction, target)         # 20.0
huber = F.huber_loss(prediction, target)   # 默认 delta=1
```

### 垃圾邮件识别：二分类

两个样本的 logits 为 $z=[2,-1]$，标签为 $y=[1,0]$。对应概率为 $[0.881,0.269]$；以 $0.5$ 为阈值时二者都被正确分类。训练时将 logits 而不是概率传入损失函数：

```python
logits = torch.tensor([2.0, -1.0])
target = torch.tensor([1.0, 0.0])          # BCE 标签使用浮点型
loss = F.binary_cross_entropy_with_logits(logits, target)

probability = torch.sigmoid(logits)         # 仅用于推理或指标
prediction = probability >= 0.5
```

若误写为 `binary_cross_entropy_with_logits(torch.sigmoid(logits), target)`，sigmoid 会被重复应用，目标函数不再是期望的 BCE-with-logits。

### 手写数字：单标签多分类

设三个类别（数字 0、1、2）的两个样本 logits 和标签为

$$
\begin{aligned}
Z&=\begin{bmatrix}2&1&0\\0&1&3\end{bmatrix},\\
y&=[0,2].
\end{aligned}
$$

每个样本只有一个真类，因此标签直接是类别索引，不是 one-hot；也不应将每类独立做 sigmoid。

```python
logits = torch.tensor([[2.0, 1.0, 0.0],
                       [0.0, 1.0, 3.0]])   # (batch=2, classes=3)
target = torch.tensor([0, 2])               # (2,)，整型类别索引
loss = F.cross_entropy(logits, target)

predicted_class = logits.argmax(dim=1)      # tensor([0, 2])；无需先 softmax
```

### 图片标签检索：多标签分类

若一张图可同时含“狗”和“草地”，类别不再互斥。类别顺序为 `[狗, 猫, 草地]` 时，logits $[2,-1,0.5]$ 对应标签 $[1,0,1]$，三个概率约为 $[0.881,0.269,0.622]$，每类独立与阈值比较。

```python
logits = torch.tensor([[2.0, -1.0, 0.5]])
target = torch.tensor([[1.0, 0.0, 1.0]])    # 与 logits 同形状
loss = F.binary_cross_entropy_with_logits(logits, target)

predicted_tags = torch.sigmoid(logits) >= 0.5  # [[True, False, True]]
```

这里使用 softmax 会错误地迫使三个概率之和为 $1$，从而让“狗”和“草地”相互竞争。

### 前景分割：BCE 与 Dice 联合

对 $2\times2$ 二值掩码，标签为 $y=[1,1,0,0]$，预测概率为 $p=[0.9,0.6,0.3,0.1]$。忽略 $\epsilon$ 时，软 Dice 为

$$
\frac{2(0.9+0.6)}{0.9+0.6+0.3+0.1+1+1}=\frac{3}{3.9}\approx0.769,
$$

Dice 损失约为 $0.231$。实际训练常将像素级 BCE 与 Dice 损失相加；其权重应在验证集上选择。

```python
logits = torch.tensor([[[[2.2, 0.4], [-0.8, -2.2]]]])  # (N, C, H, W)
target = torch.tensor([[[[1.0, 1.0], [0.0, 0.0]]]])

bce = F.binary_cross_entropy_with_logits(logits, target)
probability = torch.sigmoid(logits)
eps = 1e-6
dice = (2 * (probability * target).sum() + eps) / (probability.sum() + target.sum() + eps)
loss = bce + (1 - dice)
```
