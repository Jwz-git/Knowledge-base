# 正则化（Regularization）

> [!abstract] 核心结论
> 正则化通过加入约束、先验、扰动或模型选择规则，控制模型对训练数据偶然模式的依赖。目标是改善未见数据上的表现，而不是单纯减小参数或提高训练难度；是否有效必须由独立验证结果判断。

## 核心概念

正则化是在训练目标、模型结构、数据处理或训练过程加入限制，使模型更偏向某些较简单、较稳定或符合任务先验的解。它主要用于缓解**过拟合**：训练误差持续下降而验证表现不再改善或开始恶化。正则化不能保证提高指标；若模型本已欠拟合，过强约束通常会使训练集和验证集都变差。

欠拟合、过拟合及泛化差距的通用定义和诊断顺序见 [[机器学习#欠拟合、过拟合与泛化]]；本文重点说明确定存在过拟合后，可以使用哪些正则化手段，以及如何控制强度。

设经验损失为

$$
\mathcal{L}_{\mathrm{data}}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f_\theta(x_i),y_i),
$$

参数正则化常将训练目标写为

$$
\mathcal{L}(\theta)=\mathcal{L}_{\mathrm{data}}(\theta)+\lambda\Omega(\theta),
$$

其中 $\theta$ 为可训练参数，$\Omega$ 为惩罚项，$\lambda\geq0$ 控制强度。不同方法约束的对象不同：有的约束参数大小，有的扰动模型结构，有的扩充数据分布。

**例子**：若模型训练准确率为 $99\%$、验证准确率为 $80\%$，加入适度正则化后变为 $96\%$ 和 $85\%$，说明泛化差距缩小。若训练和验证准确率本来都只有约 $70\%$，继续增强正则化通常只会加重欠拟合。

## 常见方法

### L2 正则化与权重衰减（Weight Decay）

**定义**：L2 正则化使用参数平方和作为惩罚：

$$
\Omega(\theta)=\frac{1}{2}\lVert\theta\rVert_2^2.
$$

其梯度为 $\lambda\theta$。对 SGD（不含动量的基本形式），一步更新为

$$
\theta\leftarrow\theta-\eta(\nabla_\theta\mathcal{L}_{\mathrm{data}}+\lambda\theta)
=(1-\eta\lambda)\theta-\eta\nabla_\theta\mathcal{L}_{\mathrm{data}},
$$

即每一步都将参数按比例向零收缩，因此常称为权重衰减。

训练数据有限时，许多参数组合都能得到相近的训练误差；L2 让优化器在这些解中更偏向较小权重的解。较小权重通常减弱单个输入扰动被层层放大的程度，也减少模型依赖极端系数组合的机会，因此常作为稳定而低成本的默认约束。

**作用与局限**：较小的权重通常对应更平滑、对输入微小变化不那么敏感的函数，但这是一种倾向而非普适保证。通常不对 bias 和归一化层的缩放/偏移参数使用 weight decay；是否排除应以目标架构和已有训练配方为准。

对 SGD，L2 惩罚与“解耦权重衰减”可等价；对 Adam 一类自适应优化器则一般不等价，因为 L2 梯度会被逐参数的自适应缩放。实践中常使用 AdamW：将参数收缩与自适应梯度更新分开执行。

**例子**：若 SGD 的学习率 $\eta=0.1$、$\lambda=0.01$，且暂不考虑数据损失梯度，则参数 $2$ 更新为 $(1-0.001)\times2=1.998$。衰减很小但会在大量步数中累积；因此 $\lambda$ 需结合学习率、训练步数和优化器一起调节。

### L1 正则化与稀疏性

**定义**：L1 正则化使用绝对值之和：

$$
\Omega(\theta)=\lVert\theta\rVert_1=\sum_j|\theta_j|.
$$

在 $\theta_j\ne0$ 处，其（次）梯度为 $\operatorname{sign}(\theta_j)$；在零点不可导，但可用次梯度或近端算法处理。

L1 对非零参数施加近似恒定的收缩压力，小系数不会像 L2 那样在接近零时迅速减弱，因此更容易被推到精确的零。若任务假设只有少数特征真正有用，这种稀疏偏好可以同时控制复杂度并得到更紧凑的线性模型。

**作用与局限**：L1 倾向于使一部分参数精确变为零，因此常用于线性模型中的特征选择和稀疏建模。深度网络中，直接加 L1 不一定带来实际加速：未结构化的零权重只有在稀疏算子、剪枝或专用硬件支持下才会显著减少推理成本。

**例子**：某线性回归在无正则化时两个系数为 $[2.1,0.08]$，第二个特征几乎没有额外预测价值。加入 L1 后，结果可能变为约 $[1.9,0]$；L2 更可能得到类似 $[1.8,0.04]$ 的结果，即缩小两个系数但不产生精确的零。数值仅用于说明两种惩罚的典型差异。

### Elastic Net

**定义**：Elastic Net 同时使用 L1 和 L2：

$$
\mathcal{L}=\mathcal{L}_{\mathrm{data}}+\lambda_1\lVert\theta\rVert_1+\frac{\lambda_2}{2}\lVert\theta\rVert_2^2.
$$

L1 负责把弱特征压到零，L2 则让相关特征的系数更平滑地共同收缩。两种几何偏好叠加后，在“希望稀疏”但特征又高度相关的场景中，通常比单独使用 L1 更稳定。

**作用与局限**：它结合 L1 的稀疏性与 L2 的稳定收缩。在特征高度相关时，纯 L1 可能任意保留其中少数特征；加入 L2 往往能让解更稳定，但不消除所有相关特征带来的解释困难。

**例子**：在文本词袋模型中，“汽车”和“车辆”两个特征高度相关。纯 L1 可能在不同数据划分中交替保留其中一个；Elastic Net 的 L2 部分可让二者共同保留较小权重，而 L1 部分继续剔除大量无关词。最终仍应通过交叉验证选择 $\lambda_1,\lambda_2$。

### Dropout

**定义**：训练时，以概率 $p$ 将激活中的元素置零；采用 inverted dropout 时，保留的元素除以 $1-p$：

$$
\begin{aligned}
\tilde h&=\frac{m\odot h}{1-p},\\
m_j&\sim\operatorname{Bernoulli}(1-p).
\end{aligned}
$$

如果某个单元只能依赖固定的少数同伴，训练时随机移除这些同伴会迫使它在多种子网络中仍提供有用表示。推理时关闭随机屏蔽，相当于用一次确定性计算近似整合许多共享参数的子网络，因此可降低对特定激活路径的依赖。

**作用与局限**：随机屏蔽特征，减少单元之间的共适应。由于训练阶段已做缩放，推理阶段关闭 dropout 且不再额外缩放。dropout 常用于全连接层或 Transformer 的特定位置；在现代卷积网络、强数据增广或大规模预训练模型中，是否有益取决于整体配方，不能默认叠加得越多越好。

**例子**：$h=[2,4]$、$p=0.5$，若掩码为 $m=[1,0]$，训练时输出为 $[4,0]$；其随机期望仍为 $[2,4]$。实际一次前向传播的结果会变化，推理时则使用原始 $[2,4]$。

### 数据增广（Data Augmentation）

**定义**：对训练样本施加在任务语义上应保持标签不变或按规则变化的变换，以构造更多训练视图。例如图像的随机裁剪、水平翻转、颜色扰动；文本的掩码、同义改写则需要更谨慎的语义验证。

增广把“这些变化不应改变答案”的任务先验直接写进训练数据。模型若想同时正确处理原样本及其多个变体，就更难只记住像素位置、颜色或表面措辞等偶然细节，并能在合理变换覆盖的邻域内获得更稳定的预测。

**作用与局限**：数据增广将先验直接施加于输入分布，常比单纯惩罚权重更贴近任务。关键前提是标签语义正确：自然图像分类中水平翻转通常合理，但文字识别、左右有语义差异的医学图像或交通标志任务中可能不合理。

**例子**：训练猫狗分类器时，随机水平翻转通常仍保持“猫/狗”标签；若任务是区分字母 `b` 与 `d`，同样的翻转会改变标签或产生无效样本，不能直接使用。

### Early Stopping

**定义**：在独立验证集指标连续若干轮未改善后停止训练，并恢复验证指标最佳时的模型参数。等待轮数常称为 patience。

神经网络常先学习容易复用的主规律，随后继续降低训练损失时逐渐适应噪声和个别样本。用验证曲线选择训练时刻，相当于限制有效训练复杂度；当后续更新只改善训练集却损害验证集时，保留较早 checkpoint 更符合泛化目标。

**作用与局限**：它限制模型继续拟合训练集噪声的机会，同时节约训练时间。验证集既用于早停又反复用于调参时，会产生选择偏差；最终报告泛化性能仍应使用未参与选择的测试集，或采用嵌套交叉验证。

**例子**：若验证损失在第 12 轮达到最低、之后连续 5 轮没有改善，patience 为 5 的训练可在第 17 轮停止，并恢复第 12 轮的权重，而不是默认使用最后一轮权重。

### 标签平滑（Label Smoothing）

**定义**：在 $K$ 分类问题中，将 one-hot 目标 $y$ 与均匀分布混合：

$$
y'=(1-\varepsilon)y+\varepsilon\frac{\boldsymbol{1}}{K},
$$

其中 $\varepsilon\in[0,1]$ 为平滑系数。

one-hot 监督持续奖励更大的真类 logit 与更小的其余类 logit，容易把标签噪声和偶然样本也拟合成极端置信度。标签平滑给非真类保留少量目标质量，削弱无界扩大 logit 间隔的动力，因此可作为分类模型的轻量正则化。

**作用与局限**：它降低模型对训练标签给出极端置信度的倾向，常用于分类和 Transformer 训练。它并不总能改善概率校准，也不适合把确实需要非常尖锐后验分布的目标一概平滑；应同时检查准确率、负对数似然和校准指标。

**例子**：$K=4$、$\varepsilon=0.1$，真实类别为第 2 类时，目标从 $[0,1,0,0]$ 变为 $[0.025,0.925,0.025,0.025]$。

## 作用与局限

正则化通过限制参数、表示或训练数据的有效自由度，降低模型拟合训练集偶然模式的倾向。它只能在过拟合确实存在、约束与任务假设相符且强度合适时改善泛化；不能修复数据泄漏、错误标签、训练/部署分布偏移或模型本身欠拟合。多个方法同时加入时，效果也不能简单相加：它们可能重复施加同类约束，因而需要以独立验证结果决定保留与强度。

| 维度 | 主要作用 | 核心局限或风险 |
| --- | --- | --- |
| 容量控制 | 限制模型可利用的自由度，减少对训练样本细节的记忆 | 约束过强会导致欠拟合，且“参数更少”不总等于“泛化更好” |
| 先验注入 | 鼓励稀疏、平滑、不变性或其他符合任务经验的解 | 先验与真实任务不一致时会主动压制有效模式 |
| 随机扰动 | 降低模型对单一路径、特征或训练视图的依赖 | 会增加优化难度和训练方差，不同扰动可能相互叠加 |
| 数据覆盖 | 扩展训练分布中合理的输入变化，提高样本利用率 | 无效或越界的变换会改变标签含义并引入系统性错误 |
| 模型选择 | 利用验证信号选择训练轮次、超参数或模型版本 | 反复针对同一验证集调节会产生选择偏差 |

**例子**：若同时使用强数据增广、较大 weight decay 和高比例 dropout，训练准确率从 $90\%$ 降到 $65\%$，验证准确率也同步下降，就不是“正则化还不够”，而是约束叠加过强。应逐项减弱并用相同训练预算重新比较。

## 相关知识

### 正则化与归一化层的关系

BatchNorm、LayerNorm 等归一化层的首要目的通常是改善优化和数值尺度，而不是作为严格定义的正则化项。BatchNorm 在训练时使用小批量统计量，确实会引入随机性，有时表现出正则化效果；该效果依赖 batch size、数据和位置。不能因此用它替代针对过拟合的验证与正则化选择。

**例子**：某通道在一个 batch 中的激活为 $[1,2,3,4]$，BatchNorm 会使用该 batch 的均值 $2.5$ 和方差进行标准化；换一个 batch，统计量也会变化。这种随机性可能带来轻微正则化效果，但推理时改用运行统计量，说明它的首要作用仍是控制特征尺度与优化行为。

## 如何选择与诊断

| 场景或现象 | 优先选择或动作 | 重点检查 |
| --- | --- | --- |
| 尚无成熟训练配方 | 从适度 weight decay、任务合理的数据增广和早停开始 | 不要同时叠加强增广、高 dropout 和大权重衰减 |
| 训练指标高、验证指标明显低 | 先检查数据泄漏与分布差异，再逐项比较正则化方法 | 固定数据划分、随机种子和训练预算，比较多次运行结果 |
| 训练与验证指标都低 | 优先排查模型容量、输入特征、优化和标签 | 先完成小数据过拟合测试，不要继续增强正则化 |
| 验证曲线剧烈波动 | 检查学习率和评估流程，并考虑扩大验证集或交叉验证 | 报告均值、标准差或置信区间，而非单次峰值 |
| 需要稀疏线性模型 | 比较 L1 与 Elastic Net | 检查被选特征在不同数据划分和重采样下是否稳定 |
| 比较多个正则化方案 | 一次只改变少数因素，并记录最佳 checkpoint 的选择规则 | 测试集不得参与调参，验证集也不应被无限次试验过度拟合 |

## 综合例子

### 图像分类：PyTorch 训练流程

以下示例以 CIFAR-10 分类为例。它同时使用合理的图像增广、带 dropout 的小型卷积网络、AdamW 的解耦 weight decay、标签平滑和验证集早停。数值只是可复现的起点，不是对所有数据集都合适的最优配置。

```python
import copy
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

train_tf = transforms.Compose([
    transforms.RandomCrop(32, padding=4),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),
                         (0.2470, 0.2435, 0.2616)),
])
eval_tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),
                         (0.2470, 0.2435, 0.2616)),
])

train_set = datasets.CIFAR10("data", train=True, download=True,
                             transform=train_tf)
val_set = datasets.CIFAR10("data", train=False, download=True,
                           transform=eval_tf)  # 示例中暂作验证集；正式测试应另留测试集
train_loader = DataLoader(train_set, batch_size=128, shuffle=True)
val_loader = DataLoader(val_set, batch_size=256)

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Dropout(p=0.2), nn.Linear(128, 10),
        )

    def forward(self, x):
        return self.classifier(self.features(x))

device = "cuda" if torch.cuda.is_available() else "cpu"
model = SmallCNN().to(device)

decay, no_decay = [], []  # 仅对卷积/线性权重衰减；bias 不衰减。
for name, param in model.named_parameters():
    (no_decay if name.endswith("bias") else decay).append(param)
optimizer = torch.optim.AdamW([
    {"params": decay, "weight_decay": 1e-4},
    {"params": no_decay, "weight_decay": 0.0},
], lr=3e-4)
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)

@torch.no_grad()
def evaluate(model, loader):
    model.eval()                         # 关闭 dropout，使用 BatchNorm 的推理行为
    correct = total = 0
    for x, y in loader:
        logits = model(x.to(device))
        correct += (logits.argmax(1).cpu() == y).sum().item()
        total += y.numel()
    return correct / total

best_acc, best_state, stale_epochs = -1.0, None, 0
patience = 8
for epoch in range(100):
    model.train()                        # 开启 dropout 与训练时的数据增广
    for x, y in train_loader:
        logits = model(x.to(device))
        loss = criterion(logits, y.to(device))
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    val_acc = evaluate(model, val_loader)
    if val_acc > best_acc:
        best_acc = val_acc
        best_state = copy.deepcopy(model.state_dict())
        stale_epochs = 0
    else:
        stale_epochs += 1
        if stale_epochs >= patience:
            break

model.load_state_dict(best_state)        # 恢复最佳验证 checkpoint
print(f"best validation accuracy: {best_acc:.3f}")
```

这个例子中，随机裁剪与翻转只作用于训练集；验证时只进行确定性的张量转换与归一化。`model.train()` 和 `model.eval()` 也不可混用：前者使 dropout 随机失活，后者关闭该随机性。代码将 CIFAR-10 官方测试集临时用作验证集只是为了简化演示；真实实验应从训练集划分验证集，保留测试集直到最终评估。
